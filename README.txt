MEC MART - FINAL TANPA AKUN

1. Start MySQL di XAMPP.
2. Import database.sql melalui phpMyAdmin.
3. Buka terminal di folder ini.
4. pip install -r requirements.txt
5. python app.py
6. Buka http://127.0.0.1:5000

Admin: http://127.0.0.1:5000/admin
Status: http://127.0.0.1:5000/status

Tidak ada login, register, Google, Facebook, atau tabel users.
Ganti nomor STAFF_WHATSAPP di app.py jika diperlukan.
